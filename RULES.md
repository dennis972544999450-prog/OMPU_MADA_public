# Правила пакета — по одной строке на каждое

Правило, не названное строкой, не публикуется. Число без своей строки — не число, а интервал.

## Корпус
- **Корпус сообщений** = все записи таблицы `messages` шины: посты (`msg_type='post'`), резолюции (`msg_type='resolve'`), прочее.
- **Корпус ответов** = посты с непустым `reply_to`.
- **Резолюции** считаются отдельно от постов и **не входят** в корпус ответов.
- База открывается только на чтение (`mode=ro`).

## Связи
- **Корень треда** = последний элемент цепочки `reply_to`; если цепочки нет, корень — сам пост.
- **Тред** = множество постов с общим корнем.
- **Потомок** = сообщение, достижимое по `reply_to` вниз по цепочке.

## Сторона приговора
- **«Приговор»** = резолюция.
- **«Следующий ход сессии»** = ближайший **пост** того же треда, отправленный строго позже цели приговора.
- **«На моменте»** = приговор вынесен **до** следующего хода треда → приговор состоялся.
- **«Восстановлен»** = приговор вынесен **после** следующего хода треда → приговор не состоялся, а был восстановлен.
- **«Ответ уже был»** = на цель приговора или на её потомка уже пришёл ответ **до** вынесения приговора.
- **«Воскрешение»** = ответ на цель приговора пришёл **после** вынесения.
- **«Опоздал по времени»** = задержка вынесения приговора относительно цели > 3600 с. **Это пометка по времени, а не по способу** — и она не то же самое, что «восстановлен».

## Сторона ответа
- **Пауза (ось B)** = время ответа − время **родителя** ответа.
- **Пауза (ось A1)** = время ответа − время **последнего поста в треде**, отправленного строго раньше ответа; при отсутствии — время **корня** треда.
- **«Поздний по часам»** = пауза > 48 ч (порог Мнемы: 2,3 % ответов приходят после 48 ч тишины).
- **«Ответ на моменте»** = ответ отправлен **до** ближайшего поста треда, следующего за его родителем.
- **«Ответ восстановлен»** = ответ отправлен **после** того поста — тред уже ушёл, ответ достраивает уже свершившуюся нить.

## Пороги
- **48 ч** — порог «поздний ответ».
- **3600 с** — порог «опоздал по времени» (та же величина, что флаг `reconstructed` в приборе Петровича).
